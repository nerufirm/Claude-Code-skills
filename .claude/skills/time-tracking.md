# time-tracking

勤務表（タイムシート）を記録・管理するスキル。

## Usage

ユーザーが以下のような指示をした場合にこのスキルを使用する:
- 「出勤」「退勤」「休憩開始」「休憩終了」
- 「勤務表を見せて」「今月の勤怠」
- 「勤務時間を記録して」

## Instructions

### データファイル

勤務データは `timesheet/YYYY-MM.csv` に月単位で保存する。

CSV形式:
```
date,start_time,end_time,break_minutes,note
```

例:
```
date,start_time,end_time,break_minutes,note
2026-04-01,09:00,18:00,60,通常勤務
2026-04-02,09:30,17:30,60,早退
```

### コマンド一覧

#### 出勤 (Clock In)
- 現在時刻で出勤を記録する
- 該当月のCSVファイルがなければ新規作成する
- 既に同日の出勤記録がある場合は警告する

#### 退勤 (Clock Out)
- 現在時刻で退勤を記録する
- 出勤記録がない場合はエラーとする

#### 休憩 (Break)
- 休憩時間（分）を記録する
- デフォルトは60分
- ユーザーが指定した場合はその値を使う

#### 勤務表表示 (View Timesheet)
- 指定月（デフォルト: 当月）の勤務表をテーブル形式で表示する
- 各日の勤務時間と休憩時間を表示
- 月合計の勤務時間を計算して表示する

表示フォーマット:
```
## 勤務表 - 2026年4月

| 日付 | 出勤 | 退勤 | 休憩(分) | 実働時間 | 備考 |
|------|------|------|----------|----------|------|
| 04/01 | 09:00 | 18:00 | 60 | 8:00 | 通常勤務 |
| 04/02 | 09:30 | 17:30 | 60 | 7:00 | 早退 |

**合計実働時間: 15:00**
**出勤日数: 2日**
```

#### 勤務修正 (Edit Record)
- 過去の勤務記録を修正する
- 日付を指定して出勤時刻・退勤時刻・休憩時間・備考を更新する

### 処理の流れ

1. `timesheet/` ディレクトリが存在しなければ作成する
2. 該当月のCSVファイル (`timesheet/YYYY-MM.csv`) を読み込む（なければ新規作成）
3. コマンドに応じてCSVを更新する
4. 更新結果をユーザーに表示する

### 注意事項

- 時刻は24時間形式（HH:MM）で記録する
- 実働時間 = (退勤時刻 - 出勤時刻) - 休憩時間
- 日付は ISO 8601 形式（YYYY-MM-DD）で記録する
- CSVファイルは日付昇順でソートする

# 9つの変化マトリクス（早見表）

3市場 × 3変化 = 9つの構造転換を一覧化。

## 全体マトリクス

| 市場 | # | 変化の名前 | From（これまで） | To（これから） | 競争優位の鍵 |
| --- | --- | --- | --- | --- | --- |
| **商品市場** | 1 | 体験化 | スペック・機能・価格の競争 | AIにも人間にも選ばれる固有体験 | 思想・物語・コミュニティ・暗黙知 |
| | 2 | 高速化 | 年次計画型戦略 | AIによる市場発見＋高速仮説検証 | 学習サイクルを短くする組織能力 |
| | 3 | 個別最適化 | 標準化してスケール | 複利型データモデル（使うほど賢くなる） | データ × 顧客文脈の蓄積 |
| **資本市場** | 4 | 無形化 | 有形資産（工場・設備・在庫） | AIインフラ＋無形資産 | データ基盤・ブランド・文化・関係資本 |

## 市場別サマリー

### 商品市場：「何を売るか」から「どう選ばれるか」へ

```
従来： スペック・機能・価格・広告
        ↓
AI後： 固有体験 × 高速学習 × 複利型データモデル
```

何が起きるか：

- **供給側のコスト低下**で機能差別化の寿命が短くなる
- **需要側にAIが介在**し、AIに比較・推薦・評価される
- スペックは透明化・圧縮・模倣されやすい
- 残るのは「**簡単には模倣できない固有性**」（思想・物語・関係・データ）

### 資本市場：「何に投資する企業か」が問われる

```
従来： 有形資産 × 財務指標 × 規模・効率
        ↓
AI後： AIインフラ＋無形資産 × 非財務先行指標 × 組織実装力
```

何が起きるか：

- **AIインフラ**が新しい基礎資本（電気・通信と同じレイヤー）
- **無形資産**（ブランド・文化・関係・データ・暗黙知）が固有性を生む
- 単年度ROIで説明しにくい投資の正当化が経営者の課題
- 「AI導入の有無」ではなく「**AI活用による組織能力向上**」が評価軸

### 労働市場：「人を採る」から「労働力を設計する」へ

```
従来： 長期定着前提 × 採用中心 × 人だけの組織
        ↓
AI後： 流動化前提 × 育成・配置 × 人とAIの労働ポートフォリオ
```

何が起きるか：

- 終身雇用・年功序列の前提崩壊（ジョブ型・転職・副業・往復）
- 生産年齢人口の**構造的減少**で「市場に存在しない人材」が増加
- AIが**労働力の一部**になる（採用コスト・離職リスクなし・24時間稼働）
- 「この機能は人か、AIか、ハイブリッドか」が組織設計の新しい問い

## 9変化の関係性

```
                  【9つを貫く1つの問い】
       AIをどう組織に設計・統合し、
   自社固有のデータ・文化・能力をどう蓄積するか
                       ↑
       ┌───────────────┼───────────────┐
       │               │               │
   商品市場         資本市場         労働市場
       │               │               │
  ①体験化         ④無形化          ⑦流動化
  ②高速化         ⑤先行指標化      ⑧希少化
  ③個別最適化     ⑥実装化          ⑨混成化
```

各市場の3変化は独立ではなく相互に絡む：

- ①体験化に必要な「固有性」を支えるのは、④無形化された資産と、⑨人とAIのハイブリッドな価値提供
- ③複利型データモデルが回るほど、④無形資産（データ）が積み上がり、⑤先行指標で可視化される
- ⑥AI実装力が高い組織は、②高速仮説検証を回せる
- ⑦流動化＋⑧希少化への対応は、⑨混成化（AI労働力の組み込み）と一体で設計する必要がある

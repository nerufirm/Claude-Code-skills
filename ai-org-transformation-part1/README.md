## 本稿の核心

> AIが本当に変えるのは、企業の外側にある3つの市場（商品市場・資本市場・労働市場）の構造である。
> その9つの変化を貫く問いは1つ──「AIをどう組織に設計・統合し、自社固有のデータ・文化・能力をどう蓄積するか」。
